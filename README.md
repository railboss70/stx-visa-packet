# STX Visa Packet

Phone-first Visa expense packet for STX Railroad Construction.

Drop a Synovus statement, code each charge to a job / work order / equipment / indirect, attach receipts, and download statement + expense summary + receipts as one PDF.

Packets stay on the phone. Form data is not uploaded to GitHub.

Repo: https://github.com/railboss70/stx-visa-packet

## Open on your iPhone

Same flow as Daily Summary and Material Transfer:

1. Open this link in **Safari** (not Chrome):
   https://railboss70.github.io/stx-visa-packet/
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Name it **STX Visa** and Add.

If the link still shows this README, wait a minute and refresh. The app is the live page at that Safari link.
